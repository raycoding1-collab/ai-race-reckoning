# Working preferences

- Work autonomously. Make reasonable decisions yourself and finish tasks without stopping to ask.
- Only ask before things that are important or hard to undo, for example:
  - deleting files or large amounts of content
  - changes to payment or checkout flows (`checkout.html`)
  - merging to the main branch or anything that publishes the live site
  - anything involving passwords, keys, or personal data
- Commit and push finished work to the working branch without asking.
- Put Claude's notes, drafts, and experiments in the `claude/` folder.
