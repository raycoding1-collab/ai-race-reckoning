# Claude workspace

This folder is reserved for work done by Claude (Claude Code).

Notes, drafts, scripts and experiments created by Claude go here, kept
separate from the published site files in the repository root
(`index.html`, `checkout.html`, `dark-templates.html`, etc.).

## Contents

- [`race.html`](race.html) — **The Race Game**, an interactive toy model of AI racing
  dynamics. You run one of four labs and choose how much to invest in safety.
  Once merged to the main branch it will be live at `/claude/race.html` on the site.
